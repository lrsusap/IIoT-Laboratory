
# Arquitectura del Laboratorio IIoT

## 1. Propósito

Este directorio contiene la documentación de arquitectura
del Laboratorio IIoT.

Su función es describir la organización física, lógica,
funcional y tecnológica de la plataforma experimental,
manteniendo la trazabilidad de las decisiones de ingeniería.

## 2. Arquitectura general

El laboratorio utiliza como caso de estudio un conjunto
motor-bomba y está organizado en cinco fases:

1. Sensado y adquisición.
2. Comunicaciones y computación Edge.
3. Supervisión y persistencia.
4. Analítica de datos.
5. Inteligencia artificial y mantenimiento predictivo.

## 3. Dominios transversales

La arquitectura integra:

- Ingeniería de mantenimiento y gestión de activos.
- Instrumentación y sistemas embebidos.
- Redes y telecomunicaciones industriales.
- Ciberseguridad OT/IT.
- Gestión de datos y analítica.
- Transformación Digital Industrial e Industria 4.0.

## 5. Control de cambios

Las modificaciones de arquitectura deberán:

1. Identificar los componentes afectados.
2. Justificar técnicamente los cambios.
3. Evaluar compatibilidad y riesgos.
4. Actualizar diagramas y documentación.
5. Registrar las pruebas correspondientes.
6. Vincular las decisiones importantes con un ADR.
