
# Documentación Técnica — Laboratorio IIoT

## Propósito

Este directorio contiene la documentación de ingeniería
del Laboratorio IIoT.

Su objetivo es mantener la trazabilidad del diseño,
implementación, configuración, verificación y evolución
de los distintos subsistemas.

## Estructura documental

| Directorio | Contenido |
|-----------|-----------|
| master-guide/ | Guía Técnica y versiones oficiales |
| architecture/ | Arquitectura física, lógica y funcional |
| decisions/ | Decisiones de ingeniería y ADR |
| procedures/ | Instalación, pruebas y puesta en servicio |
| standards/ | Normas y buenas prácticas aplicables |
| project-management/ | Planes, riesgos e hitos del proyecto |

## Documento maestro

La referencia técnica principal es:

**Guía Técnica del Laboratorio IIoT — Versión 6.1**

La guía comprende las cinco fases de implementación
y los dominios transversales de mantenimiento,
telecomunicaciones, ciberseguridad y analítica.

## Control documental

Cada documento deberá identificar, según corresponda:

- Título y propósito.
- Versión o revisión.
- Autor o responsable.
- Fecha de actualización.
- Componentes afectados.
- Estado de implementación o validación.
- Referencias y evidencias relacionadas.

## Estados documentales

- PROPUESTO: diseño pendiente de aprobación.
- APROBADO: contenido revisado y aceptado.
- IMPLEMENTADO: configuración aplicada.
- VALIDADO: implementación comprobada mediante pruebas.
- OBSOLETO: documento reemplazado por una revisión.

## Principio de ingeniería

La existencia de una configuración documentada
no demuestra su funcionamiento físico.

Toda declaración de validación debe contar
con evidencia técnica reproducible.
